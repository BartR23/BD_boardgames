2. Opis tabel bazy danych i ich funkcji
Tabela Gry_planszowe zawiera następujące atrybuty: numer id gry planszowej (klucz główny), nazwę gry planszowej, nr wersji gry (jeśli jest to kolejna wersja danej gry), datę wydania tej gry (bieżącej wersji), ponadto kluczami obcymi w tabeli są atrybuty: id kategorii wiekowej z tabeli Kategorie_wiekowe, id kategorii liczby graczy z tabeli Kategorie_liczby_graczy, numer id producenta gry z tabeli Producenci, może również zawierać (jako klucze obce) numer id motywu przewodniego z tabeli Motywy oraz numer id poprzedniej wersji gry (jeśli taka istniała). Tabela ta przechowuje zasadnicze informacje o katalogowanych grach planszowych.
Tabela Motywy zawiera następujące atrybuty: numer id motywu (jako klucz główny) oraz nazwę motywu. Przechowuje ona informacje o motywach przewodnich, jakie mogą stanowić tło gier planszowych.
Tabela Kategorie_wiekowe zawiera następujące atrybuty: nr id kategorii wiekowej (jako klucz główny), nazwę kategorii oraz minimalny wiek gracza. Przechowuje ona informacje o kategoriach wiekowych, dla jakich dozwolona jest dana gra.
Tabela Kategorie_liczby_graczy zawiera następujące atrybuty: numer id kategorii liczby graczy (jako klucz główny), nazwę kategorii, minimalną liczbę graczy konieczną do rozgrywki, maksymalną liczbę graczy dozwoloną w rozgrywce (jeśli istnieje). Przechowuje ona informacje o dostępnych kategoriach liczby graczy określających dla jakiej liczby graczy dedykowana jest dana gra planszowa.
Tabela Producenci zawiera następujące atrybuty: numer id producenta gry (jako klucz główny), nazwę producenta oraz numer id lokalizacji z tabeli Lokalizacje (jako klucz obcy), w której znajduje się siedziba producenta. Przechowuje ona podstawowe informacje o producentach gier planszowych.
Tabela Lokalizacje zawiera następujące atrybuty: numer id lokalizacji (jako klucz główny) oraz nazwę kraju. Przechowuje ona nazwy lokalizacji (krajów), z których pochodzą poszczególni producenci gier planszowych.
Tabela Mechaniki zawiera następujące atrybuty: numer id mechaniki gry (jako klucz główny), nazwę mechaniki, może również zawierać krótki opis danej mechaniki (na czym polega). Przechowuje ona dostępne mechaniki gier planszowych, w oparciu o które przebiega rozgrywka.
Tabela Elementy_rozgrywki zawiera następujące atrybuty: numer id danego elementu rozgrywki (jako klucz główny), może zawierać krótki opis elementu rozgrywki (co obejmuje), jako klucze obce zawiera również id mechaniki z tabeli Mechaniki oraz id gry z tabeli Gry_planszowe. Przechowuje ona informacje o elementach rozgrywki, które składają się na daną grę, z których każdy oparty może być na innej mechanice – dana gra może składać się z jednego zasadniczego elementu rozgrywki lub kilku składowych, gdyż niektóre gry mogą być oparte na kilku mechanikach, nie tylko jednej konkretnej.
Tabela Komponenty zawiera następujące atrybuty: numer id komponentu (jako klucz główny) oraz nazwę komponentu. Przechowuje ona informacje o możliwych komponentach, jakie mogą wchodzić w skład gier planszowych.
Tabela Elementy_zestawu zawiera następujące atrybuty: numer id elementu zestawu (jako klucz główny), liczbę komponentów danego typu wchodzących w skład zestawu, a także jako klucze obce numer id komponentu z tabeli Komponenty oraz numer id gry z tabeli Gry_planszowe. Przechowuje ona informacje o wszystkich elementach wchodzących w skład poszczególnych gier planszowych – w skład gry może wchodzić wiele komponentów, a dany typ komponentu może stanowić element wielu gier, w związku z czym element zestawu określa jaki typ elementu i w jakiej ilości zawiera dana gra.
Tabela Recenzenci zawiera następujące atrybuty: numer id recenzenta (jako klucz główny, imię i nazwisko recenzenta. Przechowuje ona podstawowe dane o osobach tworzących recenzje gier planszowych.
Tabela Recenzje zwiera następujące atrybuty: numer id recenzji (jako klucz główny), krótką treść recenzji, a także jako klucze obce numer id gry z tabeli Gry_planszowe, której dotyczy dana recenzja, numer id recenzenta z tabeli Recenzenci, który stworzył daną recenzję, numer id oceny z tabeli Oceny, która to ocena jest wystawiana grze w ramach recenzji.
Tabela Oceny zawiera następujące atrybuty: numer id oceny (jako klucz główny) oraz ocenę, jaką reprezentuje. Przechowuje ona możliwe do wystawienia przez recenzentów oceny dla gier planszowych.
